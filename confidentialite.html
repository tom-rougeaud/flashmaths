Confidentialité

En bref : pas de compte, pas de nom de famille, pas d’adresse e-mail, pas de publicité, pas de cookie, pas de mesure d’audience. Les élèves jouent avec leur prénom (ou un pseudo s’ils préfèrent). Les données de jeu sont effacées automatiquement.

Aucun nom de famille, aucune adresse e-mail, aucune photo et aucune adresse IP ne sont enregistrés dans les tables de Flash Maths.

  • Le prénom suffit (jamais le nom de famille). Un pseudo au hasard est proposé pour rester discret. Le prof peut renommer ou retirer un nom inapproprié.
  • Les noms grossiers les plus courants sont refusés automatiquement.
  • Si un élève quitte la page du jeu pendant une partie (autre onglet, autre application), le prof en est averti. L’application ne sait pas quelle page a été ouverte et n’enregistre rien.
  • Le carnet garde aussi, sur l’appareil seulement, les derniers résultats par notion pour proposer « À revoir ». Rien de cela n’est envoyé au prof ni à la base.
  • L’export du carnet est un fichier que l’élève garde et protège lui-même.

  • Hébergement des pages : GitHub Pages. Comme tout hébergeur, GitHub peut conserver des journaux techniques de connexion (adresse IP) ; voir la politique de confidentialité de GitHub.
  • Base de données et temps réel : Supabase, dans le projet créé par l’enseignant (région Union européenne recommandée). Seules les données du tableau ci-dessus y sont enregistrées ; comme tout hébergeur, Supabase garde aussi des journaux techniques de connexion pendant une courte durée.
  • Aucun autre service : polices, formules et bibliothèques sont intégrées aux pages. Aucun traceur, aucun compteur de visites.

L’enseignant qui met Flash Maths en ligne et l’utilise avec sa classe est responsable de cet usage dans son établissement. Il est conseillé d’en informer les élèves et, si besoin, le délégué à la protection des données (DPO) de l’établissement ou de l’académie.

Pour toute question ou demande d’effacement anticipé, adressez-vous à votre enseignant. Pour une question sur l’outil lui-même, utilisez la page Contact.
