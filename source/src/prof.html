    Importer des questions

    Le plus simple : collez vos questions comme ceci.
    • 1ʳᵉ ligne = l’énoncé ; puis une proposition par ligne.
    • Un * devant la bonne réponse (1 à 3 mauvaises réponses).
    • = 4,5 pour une question à saisie libre (nombre, % ou expression en x). Toutes les écritures équivalentes sont acceptées : 4,5 = 4,50 = 450 % = 9/2.
    • Tuiles à associer : une paire par ligne, $6 \times 7$ => 42 (2 à 5 paires).
    • Remettre dans l’ordre : les tuiles numérotées dans le bon ordre, 1. 0,05 2. 0,5… (3 à 6) ; elles seront mélangées.
    • Estimation au curseur : ~ 1008, ou avec les bornes ~ 1008 [0 ; 2000], l’unité et la tolérance ~ 12 kg [0 ; 50] ± 2.
    • Une ligne vide entre deux questions.
    • Facultatif : # Titre pour nommer la notion, > explication, @ 45 pour 45 secondes.
    • Formules : entre dollars, par ex. $\dfrac{3}{4}$, $x^2$, $\sqrt{2}$, $u_n$.

    Ma notion

    Valeurs aléatoires (avancé)

    Une variable par ligne, par exemple a=2..9 ou p=5..50/5 (de 5 en 5). Dans les textes, écrivez {a} ou un calcul {a*p/100}. Chaque tirage donne de nouvelles valeurs.

    Modifier la question

    Zone verte = réponse ± tolérance (tous les points). Zone orange = ± 2,5 × tolérance (la moitié des points). Laissez « auto » : les bornes sont choisies pour que la réponse ne soit ni au milieu ni au bord.

    Aide rapide

    1. Choisir : le mode de jeu, un niveau, puis des notions (ou « Surprends-moi »).
    2. Générer : vérifiez les questions (réponses masquées tant que vous ne cochez pas « Afficher les réponses »). Cliquez sur un texte pour le modifier, glissez pour réordonner.
    3. Ouvrir la salle : les élèves vont sur la page élève, tapent le code et leur prénom (30 élèves maximum).
    4. Duel : chaque élève glisse son jeton dans une équipe ; vous pouvez renommer les équipes et déplacer les élèves.
    5. Classe VS Prof : « Afficher le code prof » donne le code à taper sur votre téléphone pour jouer contre la classe.
    6. Jouer : les règles s’affichent, puis les questions. « Joueurs » permet de renommer, d’exclure ou de faire entrer un retardataire (QR code). « +30 s » rallonge, « Écourter » passe au podium.

    Plusieurs salles peuvent être ouvertes en même temps sur des ordinateurs différents : chaque salle a son propre code.
